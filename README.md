# Yashna Nets

Responsive website for Yashna Nets, featuring safety nets, invisible grills, product details, and direct phone and WhatsApp links.

## Run locally

1. Install [Node.js](https://nodejs.org/) (version 20 or later).
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev` and open the local address shown in the terminal.

Create a production build with `npm run build`.

## Product content and images

Product descriptions, features, and image paths are in `src/data/products.ts`. Product photos are in `public/images/products/`. The transparent Yashna logo is in `src/assets/yashna-logo-transparent.png`.

## Contact details

Official phone and WhatsApp numbers are kept in `src/data/products.ts`. Update them there if the business contact details change.
